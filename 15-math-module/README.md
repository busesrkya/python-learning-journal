# 15 - Math Module

Covers Python's built-in `math` module: rounding, roots, logarithms,
trigonometry, factorial, GCD, and distance calculations.

Note: For heavy numerical/array work, NumPy is generally preferred in
data science and AI workflows. This is the foundational version.

`cmath` (complex number math) is intentionally skipped — not relevant
for a data science/AI learning path.
